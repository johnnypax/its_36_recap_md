# Elenco comandi git

## Inizializzazione
Per inizializzare una nuova repository usate:

```bash
git init
```

## Aggiunta alla staging area
La staging area è l'insieme di file che posso collezionare per effettuare una commit:

```bash
git add .
```

## Committment
Rendo permanenti le mie modifiche all'interno del mio PC.

```bash
git commit -m "messaggio"
```

# Faccio la push
Per rendere la repository online allineata con la mia locale:

```bash
git push
```
